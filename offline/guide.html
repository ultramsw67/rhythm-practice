앱으로

안녕하세요.
이 앱은 악보를 만들어 주고 내 연주를 녹음해 점수를 매겨 줍니다.
처음 한 번만 준비하면 그다음부터는 버튼 두세 개로 연습할 수 있습니다.
이 설명서는 화면 순서대로 모든 버튼을 하나씩 풀어 썼습니다.
처음이면 2장 "5분 만에 시작하기"만 따라 하세요.
막히면 10장 "막힐 때"를 먼저 보세요.

1. 먼저 알아 둘 것

1-1. 주소

https://ultramsw67.github.io/rhythm-practice/
카카오톡으로 받은 링크를 눌러도 되고 위 주소를 직접 쳐도 됩니다.

1-2. 준비물

① 유선 이어폰: 가장 정확합니다. 메트로놈 소리가 녹음에 섞이지 않습니다
② 블루투스 이어폰도 됩니다. 다만 소리가 조금 늦게 나오므로 지연 보정(2-3)을 꼭 하세요
③ 인터넷: 악보를 그리는 도구를 인터넷에서 불러옵니다. 인터넷이 끊기면 악보가 안 나올 때가 있습니다
④ 조용한 곳: 주변 소리가 크면 채점이 흔들립니다

1-3. 기기별 추천 브라우저

기기쓰세요피하세요
PC크롬, 엣지인터넷 익스플로러
아이폰·아이패드사파리카카오톡 안에서 바로 열기
안드로이드폰크롬카카오톡 안에서 바로 열기

카카오톡에서 링크를 누르면 카카오톡 안의 작은 브라우저로 열립니다. 여기서는 마이크가 막히거나 녹음이 저장되지 않을 수 있습니다. 화면 오른쪽 아래(또는 위)의 메뉴에서 "다른 브라우저로 열기" 를 눌러 사파리나 크롬으로 여세요.

1-4. 인터넷 없이 쓰기 (오프라인 버전)

합주실처럼 인터넷이 약한 곳에서는 오프라인 버전을 쓰세요. 연습·녹음·채점·보관함은 인터넷 버전과 똑같습니다. 화면 맨 위 제목 옆에 초록색 오프라인 표시가 붙어 있습니다.
① 휴대폰·PC 앱: 인터넷이 될 때 https://ultramsw67.github.io/rhythm-practice/offline/ 을 한 번 여세요. 설정 탭 "이 앱에 대해"에 "✅ 이 기기에 저장됨" 이 나오면 준비가 끝났습니다. 이어서 2-1처럼 홈 화면이나 바탕화면에 저장하면, 다음부터는 인터넷 없이 아이콘으로 열립니다
② PC 파일: 「리듬 연습 오프라인」 폴더를 받아 그 안의 「리듬 연습 오프라인.html」을 두 번 누르세요. 크롬이나 엣지로 열리고, 인터넷이 전혀 없어도 됩니다
③ 처음 한 번은 꼭 인터넷으로 여세요. 한 번도 열지 않은 상태에서 인터넷 없이 열면 "인터넷 연결 없음" 화면이 나옵니다
④ 앱이 새 버전으로 바뀌면 오프라인 앱은 인터넷이 될 때 한 번 열기만 해도 저절로 새 버전이 됩니다. PC 파일은 새 폴더로 바꿔 넣어야 합니다
⑤ 인터넷 버전과 오프라인 버전은 보관함이 따로입니다. 녹음을 옮기려면 한쪽에서 ⬇ 전체 백업 내보내기, 다른 쪽에서 ⬆ 백업 불러오기 를 하세요

2. 5분 만에 시작하기 (처음 한 번)

2-1. 앱처럼 저장하기 (휴대폰 홈 화면·PC 바탕화면)

한 번 저장해 두면 다음부터는 아이콘만 누르면 됩니다. 주소창 없이 앱처럼 화면 전체로 열리고 아이콘은 수트와후드 그림으로 나옵니다. 아이폰은 이렇게 해 두어야 녹음이 오래 남습니다(11장 참고).
먼저 카카오톡으로 받은 링크를 눌렀다면 "다른 브라우저로 열기" 로 사파리나 크롬에서 여세요. 카카오톡 안에서는 저장이 되지 않습니다.

① 아이폰(사파리)
1) 사파리로 앱 주소를 엽니다
2) 화면 아래 가운데의 공유 버튼(네모에 위쪽 화살표)을 누릅니다
3) 목록을 위로 밀어 홈 화면에 추가 를 누릅니다
4) 이름이 "리듬 연습"인지 보고 오른쪽 위 추가 를 누릅니다
5) 홈 화면에 생긴 리듬 연습 아이콘으로 여세요

② 안드로이드(크롬)
1) 크롬으로 앱 주소를 엽니다
2) 오른쪽 위 점 세 개(⋮) 를 누릅니다
3) 앱 설치 를 누르고 설치 를 누릅니다. 메뉴에 홈 화면에 추가 만 보이면 그것을 누르고 추가 를 누르세요
4) 홈 화면이나 앱 목록에 생긴 리듬 연습 아이콘으로 여세요
삼성 인터넷을 쓴다면: 아래쪽 메뉴(≡) → 현재 페이지 추가 → 홈 화면

③ PC(크롬·엣지)
1) 크롬이나 엣지로 앱 주소를 엽니다
2) 크롬: 주소창 오른쪽 끝의 설치 아이콘(모니터 모양)을 누르거나, 오른쪽 위 점 세 개(⋮) 메뉴에서 "설치"가 들어간 항목을 누릅니다
엣지: 오른쪽 위 점 세 개(…) → 앱 → 이 사이트를 앱으로 설치
3) 설치 를 누르면 리듬 연습이 따로 창으로 열립니다
4) 바탕화면 아이콘이 필요하면 설치할 때 나오는 "바탕화면에 바로가기 만들기"에 체크하세요. 이미 설치했다면 윈도우 시작 메뉴에서 리듬 연습 을 찾아 오른쪽 클릭 → 작업 표시줄에 고정 해도 편합니다
설치 메뉴가 안 보이면 주소창의 주소를 바탕화면으로 끌어다 놓으세요. 바로가기 아이콘이 생깁니다

앱이 새 버전으로 바뀌면 아이콘으로 열 때 저절로 새 화면이 나옵니다. 따로 다시 설치하지 않아도 됩니다.

2-2. 마이크 허용

처음 ● 녹음 시작 을 누르면 마이크를 써도 되는지 묻습니다. 허용 을 누르세요.
실수로 "허용 안 함"을 눌렀다면 아래처럼 다시 켜세요.
① PC(크롬·엣지): 주소창 왼쪽 자물쇠(또는 설정) 아이콘 → 마이크 → 허용 → 새로고침
윈도우에서 막혔다면: 윈도우 설정 → 개인 정보 및 보안 → 마이크 → 켬
② 아이폰: 주소창 왼쪽 "가가" 버튼 → 웹 사이트 설정 → 마이크 → 허용
그래도 안 되면: 설정 앱 → Safari → 마이크 → 허용
③ 안드로이드: 주소창 왼쪽 아이콘 → 권한 → 마이크 → 허용
그래도 안 되면: 휴대폰 설정 → 애플리케이션 → Chrome → 권한 → 마이크 → 허용

2-3. 지연 보정 (꼭 하세요, 1분)

휴대폰은 소리를 내고 듣는 데 시간이 조금 걸립니다. 이 시간을 재 두지 않으면 정확히 불어도 "늦게 들어갔다"고 나올 수 있습니다.
처음 앱을 열면 나오는 안내 카드의 지연 보정 먼저 하기 (1분) 를 누르거나, 아래 설정 탭으로 가세요. 녹음 칸 아래의 지연 보정 지금 재기 를 눌러도 같은 곳으로 갑니다.
① 🔊 스피커로 자동 측정: 이어폰을 빼고 휴대폰을 책상에 둔 채 조용히 기다리세요. 클릭 8번을 앱이 스스로 듣고 잽니다
② 👏 손뼉으로 측정 (이어폰): 이어폰을 끼고 클릭 8번에 맞춰 손뼉을 치세요. 블루투스 이어폰은 이 방법으로 재세요
결과가 "들쭉날쭉하다"고 나오면 한 번 더 재세요. 기기나 이어폰을 바꾸면 다시 재야 합니다.

2-4. 채점 시험 (30초)

설정 탭 → 정확한 가상 연주 를 누르세요. 앱이 스스로 연주해 채점합니다. 100점이 나오면 이 기기에서 악보와 채점이 제대로 됩니다.

4. 연습 화면

4-1. 처음 안내 카드

처음 열면 맨 위에 "처음이면 이렇게 하세요" 카드가 나옵니다. 네 단계만 따라 하면 됩니다. 다 읽었으면 알겠습니다 를 누르세요. 그러면 다시 나오지 않습니다.

4-2. 모드 고르기

버튼이럴 때
리듬 모드박자만 연습할 때. 한 줄 악보가 나오고, 한 음으로 불거나 손뼉을 쳐도 됩니다
선율 모드음정까지 연습할 때. 오선보가 나오고, 악기와 조표를 고릅니다

4-3. 악보 설정

악보 설정 칸을 누르면 펼쳐집니다. 휴대폰에서는 처음에 접혀 있고 옆에 지금 설정(예: 4/4 · 4마디 · 쉬움 · BPM 88)이 보입니다. 설정을 바꾸면 악보가 바로 새로 만들어집니다.

항목고르는 것
박자표2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 9/8, 12/8, 2/2
마디 수2·4·8·12·16마디
못갖춘마디첫 마디를 여린박으로 시작할지. "난이도에 따라"는 보통·어려움에서 가끔 나옵니다
아티큘레이션 (기호)자동 배치(앱이 붙임) / 직접 배치(내가 붙임) / 없음

4-4. 악보 위 버튼 3개

버튼하는 일

▶ 들어보기예비박 뒤에 모범 연주가 나옵니다. 다시 누르면(■ 멈추기) 멈춥니다
🔗 링크 복사지금 악보의 링크를 복사합니다. 단원에게 보내면 같은 악보가 열립니다(9장)

들어보기 중에는 지금 나는 음이 주황빨강으로 빛나고 지나간 음은 회색이 됩니다. 기호마다 소리가 다르게 납니다. 스타카토는 짧게 끊기고 악센트는 세게 시작하며 슬러는 끊김 없이 이어집니다.

4-5. 기호 직접 붙이기

음표를 누르면 아래에서 기호 창이 올라옵니다. 기호를 누르면 붙고 한 번 더 누르면 떨어집니다.
① 스타카토·스타카티시모·테누토 중 하나, 악센트·마르카토 중 하나를 붙일 수 있습니다
② 페르마타는 마지막 음에만 붙습니다
③ 슬러: 누른 음표에서 다음 음표까지 이어집니다. 슬러 바로 뒤 음표에서 누르면 그 음까지 늘어나고 슬러 안의 음표에서 누르면 지워집니다. 같은 높이 음끼리는 붙임줄과 헷갈려서 이어지지 않습니다
④ 모두 지우기: 그 음표의 기호를 다 뗍니다
⑤ 창을 닫으려면 닫기 를 누르거나 창 바깥을 누르세요

4-6. 기호 처음대로

직접 붙이거나 뗀 기호가 있으면 악보 아래에 기호 처음대로 버튼이 나옵니다. 누르면 내가 고친 기호가 모두 처음 상태로 돌아갑니다.

5. 녹음하기

5-1. 순서

① 이어폰을 끼세요 (스피커로 할 때는 듣는 방법 을 "스피커"로 바꾸세요)
② ● 녹음 시작 을 누르세요
③ 큰 숫자(1, 2, 3, 4)가 나옵니다. 이것이 예비박입니다. 숫자가 끝나면 다음 마디 첫 박부터 부세요
④ 악보에서 지금 불 음이 주황빨강으로 빛납니다. 따라가며 부세요
⑤ 끝나면 저절로 채점하고 결과 탭으로 넘어갑니다. 녹음은 보관함에 저절로 저장됩니다

5-2. 녹음 칸의 선택

선택뜻
메트로놈 소리켜면 녹음하는 동안 박자 소리가 계속 납니다. 끄면 예비박에만 납니다
예비박시작 전에 박자를 몇 마디 들을지(1마디 또는 2마디)
듣는 방법이어폰(권장) 또는 스피커. 스피커면 휴대폰을 입에서 30cm쯤 떨어뜨려 놓으세요

5-3. 녹음 중 버튼

버튼하는 일
■ 그만하기녹음을 멈춥니다. 저장하지 않습니다
↺ 처음부터예비박에서 틀렸을 때 누르세요. 멈추고 바로 다시 시작합니다

녹음하는 동안에는 악보 설정·새 악보·들어보기·다른 탭이 흐려지고 눌리지 않습니다. 실수로 악보가 바뀌지 않도록 막아 둔 것입니다. 녹음이 끝나면 다시 쓸 수 있습니다. 녹음 중에는 화면을 끄거나 다른 앱으로 넘어가지 마세요.

11. 자주 묻는 질문

Q. 녹음이 사라졌어요.
아이폰 사파리는 한동안 열지 않은 사이트의 저장 자료를 지울 때가 있습니다. 홈 화면에 올려 두고(2-1) 중요한 녹음은 백업(7-2)해 두세요. 브라우저 기록·사이트 데이터를 지워도 사라집니다.

Q. 점수가 생각보다 낮아요.
먼저 설정 → 정확한 가상 연주 가 100점인지 보세요. 100점이면 채점은 정상입니다. 그다음 지연 보정을 다시 하고 조용한 곳에서 이어폰을 끼고 녹음하세요.

Q. 박수나 목소리로 해도 되나요?
리듬 모드는 박수·입소리("따")로도 채점됩니다. 다만 음 길이와 아티큘레이션 점수는 악기로 불 때 더 정확합니다.

Q. 안내 카드를 다시 보고 싶어요.
설정 → 설정 처음 상태로 를 하면 다시 나옵니다. 이 설명서 2장과 내용이 같습니다.

Q. 연습실에 인터넷이 없어요.
오프라인 버전(1-4)을 쓰세요. 집에서 인터넷이 될 때 한 번 열어 홈 화면에 저장해 두면 연습실에서는 인터넷 없이 열립니다.

Q. 내 녹음을 다른 사람이 볼 수 있나요?
아니요. 녹음과 점수는 내 기기 안에만 있어서 소리 파일을 직접 보내지 않는 한 아무도 볼 수 없습니다.
