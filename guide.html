1-2. 준비물

① 유선 이어폰: 가장 정확합니다. 메트로놈 소리가 녹음에 섞이지 않습니다
② 블루투스 이어폰은 녹음 음질이 떨어질 수 있습니다. 켠 채 녹음하면 휴대폰이 이어폰 마이크로 바꿔 통화 음질로 녹음하기 때문입니다. 앱이 휴대폰 마이크로 바꿔 녹음을 시도하고 그래도 안 되면 알려 줍니다. 블루투스밖에 없다면 블루투스를 끄고 듣는 방법 을 "스피커"로 바꿔 녹음하세요. 소리가 조금 늦게 나오므로 지연 보정(2-3)도 꼭 하세요
③ 인터넷: 악보를 그리는 도구를 인터넷에서 불러옵니다. 인터넷이 끊기면 악보가 안 나올 때가 있습니다
④ 조용한 곳: 주변 소리가 크면 채점이 흔들립니다

1-3. 기기별 추천 브라우저

기기쓰세요피하세요
PC크롬, 엣지인터넷 익스플로러

카카오톡에서 링크를 누르면 사파리(안드로이드는 크롬)로 저절로 넘어갑니다. 카카오톡 안의 화면에서는 마이크가 막히거나 녹음이 저장되지 않아서 그렇게 해 두었습니다. 넘어가지 않고 파란 안내 화면이 나오면 노란 "사파리로 열기"(안드로이드는 "크롬으로 열기") 단추를 누르세요. 인스타그램·네이버 앱·밴드에서 열어도 같은 안내가 나옵니다.

1-4. 인터넷 없이 쓰기 (오프라인 버전)

합주실처럼 인터넷이 약한 곳에서는 오프라인 버전을 쓰세요. 연습·녹음·채점·보관함은 인터넷 버전과 똑같습니다. 화면 맨 위 제목 옆에 초록색 오프라인 표시가 붙어 있습니다.
① 휴대폰·PC 앱: 인터넷이 될 때 https://ultramsw67.github.io/rhythm-practice/offline/ 을 한 번 여세요. 설정 탭 "이 앱에 대해"에 "✅ 이 기기에 저장됨" 이 나오면 준비가 끝났습니다. 이어서 2-1처럼 홈 화면이나 바탕화면에 저장하면, 다음부터는 인터넷 없이 아이콘으로 열립니다
② PC 파일: 「수드 리듬 연습 오프라인」 폴더를 받아 그 안의 「수드 리듬 연습 오프라인.html」을 두 번 누르세요. 크롬이나 엣지로 열리고, 인터넷이 전혀 없어도 됩니다
③ 처음 한 번은 꼭 인터넷으로 여세요. 한 번도 열지 않은 상태에서 인터넷 없이 열면 "인터넷 연결 없음" 화면이 나옵니다
④ 앱이 새 버전으로 바뀌면 오프라인 앱은 인터넷이 될 때 한 번 열기만 해도 저절로 새 버전이 됩니다. PC 파일은 새 폴더로 바꿔 넣어야 합니다
⑤ 인터넷 버전과 오프라인 버전은 보관함이 따로입니다. 녹음을 옮기려면 한쪽에서 ⬇ 전체 백업 내보내기, 다른 쪽에서 ⬆ 백업 불러오기 를 하세요

2. 5분 만에 시작하기 (처음 한 번)

2-1. 앱처럼 저장하기 (휴대폰 홈 화면·PC 바탕화면)

한 번 저장해 두면 다음부터는 아이콘만 누르면 됩니다. 주소창 없이 앱처럼 화면 전체로 열리고 아이콘은 수트와후드 그림으로 나옵니다. 아이폰은 이렇게 해 두어야 녹음이 오래 남습니다(10장 참고).
카카오톡으로 받은 링크를 눌렀다면 먼저 사파리나 크롬으로 넘어갔는지 보세요. 파란 안내 화면이 보이면 노란 단추를 누르면 됩니다. 카카오톡 안에서는 저장이 되지 않습니다.

① 아이폰(사파리)
1) 사파리로 앱 주소를 엽니다
2) 화면 아래 가운데의 공유 버튼(네모에 위쪽 화살표)을 누릅니다
3) 목록을 위로 밀어 홈 화면에 추가 를 누릅니다
4) 이름이 "수드 리듬 연습"인지 보고 오른쪽 위 추가 를 누릅니다
5) 홈 화면에 생긴 수드 리듬 연습 아이콘으로 여세요

② 안드로이드(크롬)
1) 크롬으로 앱 주소를 엽니다
2) 오른쪽 위 점 세 개(⋮) 를 누릅니다
3) 앱 설치 를 누르고 설치 를 누릅니다. 메뉴에 홈 화면에 추가 만 보이면 그것을 누르고 추가 를 누르세요
4) 홈 화면이나 앱 목록에 생긴 수드 리듬 연습 아이콘으로 여세요
삼성 인터넷을 쓴다면: 아래쪽 메뉴(≡) → 현재 페이지 추가 → 홈 화면

③ PC(크롬·엣지)
1) 크롬이나 엣지로 앱 주소를 엽니다
2) 크롬: 주소창 오른쪽 끝의 설치 아이콘(모니터 모양)을 누르거나, 오른쪽 위 점 세 개(⋮) 메뉴에서 "설치"가 들어간 항목을 누릅니다
엣지: 오른쪽 위 점 세 개(…) → 앱 → 이 사이트를 앱으로 설치
3) 설치 를 누르면 수드 리듬 연습이 따로 창으로 열립니다
4) 바탕화면 아이콘이 필요하면 설치할 때 나오는 "바탕화면에 바로가기 만들기"에 체크하세요. 이미 설치했다면 윈도우 시작 메뉴에서 수드 리듬 연습 을 찾아 오른쪽 클릭 → 작업 표시줄에 고정 해도 편합니다
설치 메뉴가 안 보이면 주소창의 주소를 바탕화면으로 끌어다 놓으세요. 바로가기 아이콘이 생깁니다

앱이 새 버전으로 바뀌면 아이콘으로 열 때 저절로 새 화면이 나옵니다. 따로 다시 설치하지 않아도 됩니다.

2-2. 마이크 허용

처음 ● 녹음 시작 을 누르면 마이크를 써도 되는지 묻습니다. 허용 을 누르세요.
실수로 "허용 안 함"을 눌렀다면 아래처럼 다시 켜세요.
① PC(크롬·엣지): 주소창 왼쪽 자물쇠(또는 설정) 아이콘 → 마이크 → 허용 → 새로고침
윈도우에서 막혔다면: 윈도우 설정 → 개인 정보 및 보안 → 마이크 → 켬
② 아이폰: 주소창 왼쪽 "가가" 버튼 → 웹 사이트 설정 → 마이크 → 허용
그래도 안 되면: 설정 앱 → Safari → 마이크 → 허용
③ 안드로이드: 주소창 왼쪽 아이콘 → 권한 → 마이크 → 허용
그래도 안 되면: 휴대폰 설정 → 애플리케이션 → Chrome → 권한 → 마이크 → 허용

2-3. 지연 보정 (꼭 하세요, 1분)

휴대폰은 소리를 내고 듣는 데 시간이 조금 걸립니다. 이 시간을 재 두지 않으면 정확히 불어도 "늦게 들어갔다"고 나올 수 있습니다.
처음 앱을 열면 나오는 안내 카드의 지연 보정 먼저 하기 (1분) 를 누르거나, 아래 설정 탭으로 가세요. 녹음 칸 아래의 지연 보정 지금 재기 를 눌러도 같은 곳으로 갑니다.
① 🔊 스피커로 자동 측정: 이어폰을 빼고 휴대폰을 책상에 둔 채 조용히 기다리세요. 클릭 8번을 앱이 스스로 듣고 잽니다
② 👏 손뼉으로 측정 (이어폰): 이어폰을 끼고 클릭 8번에 맞춰 손뼉을 치세요. 블루투스 이어폰은 이 방법으로 재세요
결과가 "들쭉날쭉하다"고 나오면 한 번 더 재세요. 기기나 이어폰을 바꾸면 다시 재야 합니다.

2-4. 채점 시험 (30초)

설정 탭 → 정확한 가상 연주 를 누르세요. 앱이 스스로 연주해 채점합니다. 100점이 나오면 이 기기에서 악보와 채점이 제대로 됩니다.

4. 연습 화면

4-1. 처음 안내 카드

처음 열면 맨 위에 "처음이면 이렇게 하세요" 카드가 나옵니다. 네 단계만 따라 하면 됩니다. 다 읽었으면 알겠습니다 를 누르세요. 그러면 다시 나오지 않습니다.

4-2. 모드 고르기

버튼이럴 때
리듬 모드박자만 연습할 때. 한 줄 악보가 나오고, 한 음으로 불거나 손뼉을 쳐도 됩니다
선율 모드음정까지 연습할 때. 오선보가 나오고, 악기와 조표를 고릅니다

4-3. 악보 설정

악보 설정 칸을 누르면 펼쳐집니다. 휴대폰에서는 처음에 접혀 있고 옆에 지금 설정(예: 4/4 · 4마디 · 1단계 기본 박 · BPM 88)이 보입니다. 설정을 바꾸면 악보가 바로 새로 만들어집니다.

연습 종류 (선율 모드)선율(새 선율 만들기)·음계(스케일) 가운데 고릅니다. 음계를 고르면 고른 조의 으뜸음에서 올라갔다가 내려와 으뜸음으로 끝납니다. 난이도에 따라 리듬이 바뀝니다(1단계 4분음표, 2단계 점8분+16분, 3단계 16분음표, 4단계 16분-8분-16분 당김, 5단계 셋잇단). 2/2박자에서는 2분음표를 한 박으로 셉니다. 4단계부터는 악기 음역이 넉넉하면 두 옥타브로 나옵니다. 빠르기에 비해 리듬이 너무 빠르면 한 단계 쉬운 리듬으로 나오고, 악보 아래 정보 줄에 "이 박자·빠르기에서는 ○단계 리듬"이라고 적힙니다. 빠르기를 낮추면 고른 단계 리듬이 다시 나옵니다

10. 자주 묻는 질문

Q. 녹음이 사라졌어요.
아이폰 사파리는 한동안 열지 않은 사이트의 저장 자료를 지울 때가 있습니다. 홈 화면에 올려 두고(2-1) 중요한 녹음은 백업(7-2)해 두세요. 브라우저 기록·사이트 데이터를 지워도 사라집니다.

Q. 스윙 악보인데 8분음표가 같은 길이로 적혀 있어요.
재즈 악보는 스윙 8분음표를 곧은 8분음표로 적고 맨 위에 Swing 이라고 씁니다. 길게-짧게(셋잇단의 앞 둘 + 뒤 하나) 연주하세요. 들어보기와 채점도 그 길이에 맞춰져 있습니다.

Q. 조표 기준 칸이 흐리게 잠겨 있어요.
C 악기(플루트·오보에·트롬본·유포니움·튜바·C 악기 악보)와 더블베이스는 악보에 적힌 조가 곧 실제 소리 조라서 고를 필요가 없습니다. 클라리넷·색소폰·트럼펫·호른처럼 이조 악기를 고르면 칸이 열립니다.

Q. 점수가 생각보다 낮아요.
먼저 설정 → 정확한 가상 연주 가 100점인지 보세요. 100점이면 채점은 정상입니다. 그다음 지연 보정을 다시 하고 조용한 곳에서 이어폰을 끼고 녹음하세요.

Q. 연속일이 끊겼어요. 처음부터 다시 해야 하나요?
연속일은 1일부터 다시 시작하지만 음표 점수·칭호·배지는 그대로 남습니다. 한 주에 하루는 쉬어도 이어지니 바쁜 날에는 짧은 악보로 한 번만 녹음하세요. 기록은 그 기기·그 브라우저 안에만 남습니다. 인터넷 판과 오프라인 판도 기록이 따로 쌓입니다. 이 기능이 생긴 뒤 앱을 처음 열 때는 보관함에 있던 녹음으로 기록을 한 번 채워 둡니다.

Q. 타악기 단원도 쓸 수 있나요?
리듬 모드에서 악기 (리듬 모드) 를 드럼 세트·스네어 드럼·베이스 드럼·심벌즈 중 하나로 고르세요. 들어보기가 그 악기 소리로 나옵니다. 두드리는 악기는 소리 길이를 바꿀 수 없어서 스타카토·테누토는 붙지 않고, 채점도 음 길이는 보지 않고 박자와 세기(마르카토)만 봅니다. 드럼 세트는 4단계부터 플램이 나오고 롤은 아직 없습니다.

Q. 박수나 목소리로 해도 되나요?
리듬 모드는 박수·입소리("따")로도 채점됩니다. 다만 음 길이와 아티큘레이션 점수는 악기로 불 때 더 정확합니다.

Q. 글씨가 작아서 잘 안 보여요.
설정 → 글자 크기 → 아주 크게 를 누르세요. 버튼과 악보도 함께 커집니다. 휴대폰이 작으면 악보가 한 줄에 한두 마디씩 나옵니다.

Q. 난이도가 1~7단계에서 1~5단계로 바뀌었어요. 예전 녹음은 어떻게 되나요?
예전 녹음은 그때 악보 그대로 보입니다. 그 악보로 다시 연습하면 난이도 칸에 "이전 7단계 판"이라고 나오고, 단계 숫자를 누르면 새 5단계로 바뀝니다. 저장해 둔 설정은 1·2단계는 1단계, 3단계는 2단계, 4단계는 3단계, 5단계는 4단계, 6·7단계는 5단계로 옮겨 둡니다. 예전 7단계의 32분음표·다섯~일곱잇단은 합주곡에 거의 나오지 않아 뺐습니다.

Q. 난이도가 쉬움·보통·어려움에서 단계로 바뀌었어요. 예전 녹음은 어떻게 되나요?
예전에 녹음한 기록은 그때 악보 그대로 보이고 채점도 그대로입니다. 결과 화면의 ↺ 같은 악보 다시 녹음 이나 보관함의 이 악보로 연습 을 누르면 난이도 칸에 "이전 판 난이도" 라고 나옵니다. 이때 단계 숫자를 누르면 새 난이도로 바뀝니다. 예전에 고른 난이도는 쉬움이면 1단계, 보통이면 3단계, 어려움이면 5단계로 옮겨 둡니다.

Q. 안내 카드를 다시 보고 싶어요.
설정 → 설정 처음 상태로 를 하면 다시 나옵니다. 이 설명서 2장과 내용이 같습니다.

Q. 연습실에 인터넷이 없어요.
오프라인 버전(1-4)을 쓰세요. 집에서 인터넷이 될 때 한 번 열어 홈 화면에 저장해 두면 연습실에서는 인터넷 없이 열립니다.

Q. 내 녹음을 다른 사람이 볼 수 있나요?
아니요. 녹음과 점수는 내 기기 안에만 있어서 소리 파일을 직접 보내지 않는 한 아무도 볼 수 없습니다.
